# /kickoff

Use the `mature-app-starter` and `kickoff-runner` skills to guide a new app kickoff.

Read:

- `docs/foundation/app-startup-blueprint.md`
- `docs/foundation/kickoff-checklist.md`
- `docs/foundation/agents-md-layers.md`

Return:

- Product foundation.
- UX shape.
- Technical direction.
- Instruction files to create.
- First implementation slice.

Read `BLUEPRINT.md` first. If the optional docs library was not installed, use `.claude/skills/mature-app-starter/references/required-blueprint.md`, `expo-project-structure.md` and `kickoff-checklist.md`. Use the required Expo/Router/modules architecture, complete the project records and plan the structural check in CI. An instruction-only installation is not a completed app.
